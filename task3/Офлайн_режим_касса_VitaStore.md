# Офлайн-режим кассы VitaStore

Вся логика работы с устройствами вынесена в Local HAL / Edge Agent — лёгкий локальный сервис со встроенным офлайн-кэшем (SQLite), без отдельной администрируемой БД. Пока связь есть, Edge Agent в фоне кэширует цены и номенклатуру из облака. При обрыве интернета Cloud POS продолжает работать как тонкий клиент, но все операции с оборудованием идут через Edge Agent напрямую, а не в облако.

Продажа за наличные в офлайне проходит полностью локально: Edge Agent формирует чек по кэшированным ценам, печатает его через фискальный регистратор и ставит транзакцию в локальную очередь. Фискализация не зависит от интернета магазина — регистратор передаёт данные в ОФД по собственному независимому каналу (SIM/GPRS). Оплата картой в офлайне возможна, только если независимый канал связи есть у самого терминала — это ограничение оборудования, а не архитектуры.

После восстановления связи Edge Agent пакетно и идемпотентно отправляет накопленную очередь в облачный Sync & Queue Service, который сверяет продажи с актуальными остатками и ценами и разрешает конфликты (если цена менялась, пока магазин был офлайн — применяется значение на момент продажи). Далее события продаж уходят в SAP ERP через шину/API, а не ночным FTP, как в AS-IS. Начисление баллов лояльности требует Promo/Loyalty Engine и потому в офлайне тоже откладывается до синхронизации.
